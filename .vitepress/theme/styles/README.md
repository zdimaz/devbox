# Стили ссылок проекта

В этом файле собраны все стили для ссылок, используемые в проекте.

## Доступные классы

### Базовые стили
- `a` - базовые стили для всех ссылок
- `a:visited` - посещенные ссылки
- `a:hover` - ссылки при наведении
- `a:focus` - ссылки в фокусе

### Специальные классы

#### Внешние ссылки
```html
<a href="https://example.com" class="external-link">Внешняя ссылка</a>
```

#### Навигационные ссылки
```html
<a href="#" class="nav-link">Навигационная ссылка</a>
<a href="#" class="nav-link active">Активная ссылка</a>
```

#### Ссылки в футере
```html
<a href="#" class="footer-link">Ссылка в футере</a>
```

#### Ссылки в коде
```html
<a href="#" class="code-link">Ссылка в коде</a>
```

#### Кнопки-ссылки
```html
<a href="#" class="btn-link">Кнопка-ссылка</a>
```

#### Ссылки в карточках
```html
<a href="#" class="card-link">Ссылка в карточке</a>
```

#### Ссылки в таблицах
```html
<a href="#" class="table-link">Ссылка в таблице</a>
```

#### Ссылки в списках
```html
<a href="#" class="list-link">Ссылка в списке</a>
```

#### Ссылки без подчеркивания
```html
<a href="#" class="no-underline">Ссылка без подчеркивания</a>
```

#### Ссылки с высоким контрастом
```html
<a href="#" class="high-contrast-link">Ссылка с высоким контрастом</a>
```

## Примеры использования

### Обычная ссылка
```markdown
[Обычная ссылка](https://example.com)
```

### Внешняя ссылка
```html
<a href="https://example.com" class="external-link">Внешняя ссылка</a>
```

### Ссылка в навигации
```html
<nav>
  <a href="#" class="nav-link">Главная</a>
  <a href="#" class="nav-link active">Документация</a>
  <a href="#" class="nav-link">О проекте</a>
</nav>
```

### Ссылка в футере
```html
<footer>
  <a href="#" class="footer-link">Политика конфиденциальности</a>
  <a href="#" class="footer-link">Условия использования</a>
</footer>
```

### Кнопка-ссылка
```html
<a href="#" class="btn-link">Скачать</a>
```

## Цветовые схемы

Ссылки автоматически адаптируются под светлую и темную темы:

- Светлая тема: `text-blue-600 hover:text-blue-800`
- Темная тема: `dark:text-blue-400 dark:hover:text-blue-300`

## Адаптивность

Все стили адаптивны и работают корректно на мобильных устройствах и десктопе.

## Интеграция с UnoCSS

Стили используют UnoCSS утилиты, что обеспечивает производительность и удобство поддержки.
