# Сводка по стилям ссылок проекта

## 📁 Структура файлов

### Основные файлы стилей
- `theme.css` - основной файл стилей темы с импортом типографии
- `typography.css` - стили типографии для всех типов ссылок
- `README.md` - документация по стилям ссылок
- `usage-examples.md` - примеры использования стилей
- `SUMMARY.md` - эта сводка

## 🎨 Доступные классы стилей

### Базовые стили
- `a` - базовые стили для всех ссылок
- `a:visited` - посещенные ссылки
- `a:hover` - ссылки при наведении
- `a:focus` - ссылки в фокусе

### Специальные классы
- `external-link` - внешние ссылки с иконкой
- `nav-link` - навигационные ссылки
- `nav-link.active` - активная навигационная ссылка
- `footer-link` - ссылки в футере
- `code-link` - ссылки в коде
- `btn-link` - кнопки-ссылки
- `card-link` - ссылки в карточках
- `table-link` - ссылки в таблицах
- `list-link` - ссылки в списках
- `no-underline` - ссылки без подчеркивания
- `high-contrast-link` - ссылки с высоким контрастом

### Контекстуальные классы
- `content-link` - ссылки в контенте
- `content a` - стили для ссылок в контенте
- `.VPDoc a` - совместимость с VitePress
- `p a` - ссылки в параграфах
- `h1 a, h2 a, h3 a, h4 a, h5 a, h6 a` - ссылки в заголовках
- `.code-block a` - ссылки в кодовых блоках

## 🎯 Цветовая схема

### Светлая тема
- Основной цвет: `text-blue-600`
- При наведении: `hover:text-blue-800`
- Посещенные: `text-purple-600`

### Темная тема
- Основной цвет: `dark:text-blue-400`
- При наведении: `dark:hover:text-blue-300`
- Посещенные: `dark:text-purple-400`

## 📱 Адаптивность

Все стили адаптивны и включают:
- Медиа-запросы для мобильных устройств
- Адаптивные размеры шрифтов
- Адаптивные отступы
- Поддержка touch-устройств

## ♿ Доступность

Стили включают поддержку:
- Состояния `:focus` с outline
- Состояния `:hover` для визуальной обратной связи
- Адаптивные размеры для touch-устройств
- Контрастность согласно WCAG

## 🔧 Интеграция

### UnoCSS
Стили используют UnoCSS утилиты для производительности:
- `@apply` для применения утилит
- Кастомные шрифты и цвета
- Плавные переходы

### VitePress
Полная совместимость с VitePress:
- Автоматическая интеграция
- Сохранение стандартных стилей VitePress
- Расширение функциональности

## 📚 Использование

### Простое использование
```markdown
[Обычная ссылка](https://example.com)
```

### Расширенное использование
```html
<a href="https://github.com" class="external-link">GitHub</a>
<a href="/docs" class="nav-link active">Документация</a>
<a href="/download" class="btn-link">Скачать</a>
```

## 🎨 Кастомизация

### Изменение цветов
Можно изменить переменные в `uno.config.js`:
```js
colors: {
  blue: {
    DEFAULT: "#4d7cfe",  // Основной цвет ссылок
    100: "#c8d8ff",     // При наведении
    700: "#2855d8",     // Посещенные
  },
}
```

### Добавление новых классов
Новые стили можно добавить в `typography.css`:
```css
.custom-link {
  @apply text-green-600 hover:text-green-800;
}
```
