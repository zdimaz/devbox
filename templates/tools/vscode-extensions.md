# VSCode Extensions

## Продуктивность
1. **alefragnani.project-manager** — менеджер проектов
2. **naumovs.color-highlight** — подсветка цветов в CSS
3. **christian-kohler.npm-intellisense** — подсказки по импортам модулей
4. **CoenraadS.bracket-pair-colorizer** — подсветка скобок разными цветами
5. **dbaeumer.vscode-eslint** — интеграция ESLint в VS Code
6. **dzannotti.vscode-babel-coloring** — подсветка ошибок в ES6+ коде
7. **eamodio.gitlens** — интеграция Git, подсказки о последних изменениях
8. **formulahendry.auto-close-tag** — автоматическое добавление закрывающих тегов в HTML
9. **formulahendry.auto-rename-tag** — автоматическое переименование закрывающих тегов в HTML
10. **formulahendry.terminal** — кнопка вызова терминала в VS Code
11. **leizongmin.node-module-intellisense** — подсказки при импорте модулей Node.js
12. **mohd-akram.vscode-html-format** — форматирование HTML‑кода
13. **ms-vsliveshare.vsliveshare** — совместная работа в одном редакторе для двух удалённых пользователей
14. **pflannery.vscode-versionlens** — проверка актуальности версий пакетов в `package.json`
15. **redhat.vscode-yaml** — поддержка YAML в VS Code
16. **ricard.postcss** — поддержка PostCSS в VS Code

## Удобство
1. **k--kato.intellij-idea-keybindings** — клавиатурные сочетания как в WebStorm
2. **mikestead.dotenv** — подсветка синтаксиса в файле `.env`
3. **streetsidesoftware.code-spell-checker** — проверка орфографии английского текста
4. **wayou.vscode-todo-highlight** — подсвечивание `TODO`
5. **xabikos.JavaScriptSnippets** — набор сниппетов JavaScript
