# 17. Callbacks — колбэки (фундамент)

> Без этого раздела filter/map/reduce кажутся магией. С ним — становятся очевидностью.

## Что такое колбэк
Колбэк = функция, которую ты передаёшь ДРУГОЙ функции, а та вызывает её потом.

```js
// Ты пишешь ЧТО делать, метод решает КОГДА и С ЧЕМ
tours.filter(t => t.price < 2000);
//           ↑ это и есть колбэк. filter вызовет его для КАЖДОГО элемента
```

## Почему методы массивов — это циклы
```js
// Эти две записи делают одно и то же:
const cheap = tours.filter(t => t.price < 2000);

const cheap = [];
for (const t of tours) {          // метод сам прогоняет цикл
  if (t.price < 2000) {
    cheap.push(t);                // а твой колбэк говорит, что внутри
  }
}
```
Метод = цикл + твоя логика. Колбэк — это и есть «твоя логика».

## Колбэки везде, не только в массивах
```js
btn.addEventListener("click", () => {...});  // колбэк на событие
setTimeout(() => {...}, 1000);               // колбэк через 1 секунду
tours.map(t => t.name);                      // колбэк в методе
```

## Функция может принимать и возвращать функции
```js
const twice = f => x => f(f(x));   // функция высшего порядка (HOF)
const addOne = n => n + 1;
twice(addOne)(5);                  // 7 — (5+1)+1
```
Не пугайся — просто знай, что так бывает. В React это встретится в HOC и кастомных хуках.
